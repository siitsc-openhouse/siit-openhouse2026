Add your own questions

Edit one list
  1. Find the QUIZ list in the page's script.
  2. Replace each entry with your question, choices, the index of the right choice (counting from 0), and a one-line explanation.
  3. Do the same for CARDS. Any number of questions or cards works.
const QUIZ = {
  title: "Solar System Check",
  shuffle: false,          // true = random question order
  questions: [
    {
      q: "Which planet has the shortest year?",
      choices: ["Venus", "Mercury", "Mars", "Earth"],
      answer: 1,             // index into choices
      explain: "Mercury circles the Sun in about 88 Earth days."
    }
  ]
};

const CARDS = [
  { term: "Astronomical unit", def: "About 149.6 million km ..." }
];
